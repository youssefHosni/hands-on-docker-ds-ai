# Cloud Costs

## Budgets

Each project has a monthly cloud budget. The project lead gets an alert when 80% of the budget is
used.

## Approvals

Any new resource that costs more than 500 euros a month needs the approval of the head of data
before it is created.

## Cleaning Up

Development machines are stopped automatically at 20:00 every evening. Resources without a `project`
label are deleted after 7 days.
